핵심 공식 · 두 직선 y = mx + n, y = m′x + n′의 위치 관계
  • 평행 ⇔ m = m′, n ≠ n′ (기울기가 같고 y절편이 다름)
  • 수직 ⇔ m × m′ = −1

평행. 두 식을 같다고 놓으면 mx + n = m′x + n′입니다. m = m′이면 x가 지워지고 n = n′만 남는데, y절편이 다르면 이 식은 어떤 x에서도 성립하지 않으므로 두 직선은 만나지 않습니다.

수직. 기울기가 m인 직선에 가로 1, 세로 m인 작은 직각삼각형을 그리고, 삼각형을 통째로 원점을 중심으로 시계 반대 방향 90° 돌립니다. 오른쪽을 향하던 가로 1은 위를 향하는 세로 1이 되고, 위를 향하던 세로 m은 왼쪽을 향하는 가로 m이 됩니다. 돌아간 직선은 왼쪽으로 m만큼 가면 위로 1 올라가므로

\[ m' = \frac{1}{-m} = -\frac{1}{m} \qquad\Longrightarrow\qquad m \times m' = -1 \]

가로와 세로가 자리를 바꾸면서 역수가 되고, 오른쪽이 왼쪽으로 바뀌면서 부호가 뒤집혔습니다.

복소수. 제곱해서 −1이 되는 수를 i로 나타내고(i² = −1), a + bi 꼴의 수를 복소수라 합니다. 복소수의 곱셈은 다항식처럼 전개한 뒤 i²을 −1로 바꾸면 됩니다.

핵심 공식 · 복소수의 곱셈
\[ i^2 = -1,\qquad (a+bi)(c+di) = (ac - bd) + (ad + bc)\,i \]
예제

(1) 직선 y = 2x + 1에 수직이고 점 (2, 1)을 지나는 직선의 방정식을 구하시오.
(2) i(3 + i)를 계산하시오.

풀이 보기풀이 접기

(1) 수직인 직선의 기울기 m′은 2 × m′ = −1에서 m′ = −1/2입니다. 점 (2, 1)을 지나므로 y − 1 = −½(x − 2), 정리하면 y = −½x + 2입니다.

(2) i(3 + i) = 3i + i² = −1 + 3i입니다. 점으로 보면 (3, 1)이 (−1, 3)으로 옮겨졌습니다. 가로와 세로가 바뀌고 부호 하나가 뒤집혔으니, 위의 90° 회전과 같은 움직임입니다. 처음 점과 원점을 잇는 직선의 기울기 1/3과 옮겨진 점의 기울기 −3을 곱하면 −1입니다.

왜 리액턴스에 j가 붙을까. 저항에서는 전압과 전류가 함께 움직이지만, 코일에서는 전압이 전류보다 90° 앞서고 콘덴서에서는 90° 뒤집니다(고등 5에서 미분으로 확인합니다). "90° 돌아가 있다"를 수식으로 쓰는 방법이 j를 곱하는 것이므로, 코일은 +jXL, 콘덴서는 −jXC로 씁니다.

직렬 연결은 복소수의 덧셈. 저항, 코일, 콘덴서를 한 줄로 이으면 임피던스를 더하면 됩니다. 실수부는 실수부끼리, 허수부는 허수부끼리 더하는 교과서의 덧셈 규칙 그대로입니다.

\[ Z = R + jX_L - jX_C = R + j\,(X_L - X_C) \]

XL과 XC는 부호가 반대라서 서로 지웁니다. 둘이 똑같아져 허수부가 0이 되는 상태가 중등 3에서 본 공진입니다.

점근선. x가 1에 가까워질수록 분모 x − 1은 0에 가까워집니다. 1을 아주 작은 수로 나누면 아주 큰 수가 되므로 그래프는 x = 1 근처에서 위아래로 한없이 뻗고, x = 1에서는 값이 없습니다. 반대로 x가 한없이 커지면 1/(x − 1)은 0에 가까워집니다. 그래프가 한없이 가까워지는 이 두 직선 x = 1, y = 0을 점근선이라 합니다.

평행이동. 중등 3의 반비례 그래프 y = k/x를 x축 방향으로 p, y축 방향으로 q만큼 평행이동하면 x 대신 x − p, y 대신 y − q를 넣은 식이 됩니다.

핵심 공식 · 유리함수 y = k/(x − p) + q (k ≠ 0)
  • 점근선: 직선 x = p, 직선 y = q
  • 정의역: x ≠ p인 실수 전체 · 치역: y ≠ q인 실수 전체
  • y = (ax + b)/(cx + d) 꼴은 분자를 분모로 나누어 이 꼴로 바꿉니다
예제

유리함수 y = (2x + 1)/(x − 1)의 그래프의 점근선의 방정식을 구하시오.

풀이 보기풀이 접기

분자를 분모로 나눕니다. 2x + 1 = 2(x − 1) + 3이므로

\[ y = \frac{2(x-1) + 3}{x - 1} = \frac{3}{x-1} + 2 \]

y = 3/x를 x축 방향으로 1, y축 방향으로 2만큼 평행이동한 그래프이므로 점근선은 x = 1, y = 2입니다.

\[ \frac{1 + x}{1 - x} = \frac{(x-1) + 2}{-(x-1)} = -1 + \frac{2}{-(x-1)} = \frac{-2}{x - 1} - 1 \]

로그의 정의. 2를 몇 번 곱해야 8이 될까? 답 3을 log₂ 8로 나타냅니다. 로그는 "밑을 몇 제곱해야 그 수가 되는가"를 묻는 지수의 거꾸로입니다.

핵심 공식 · 로그의 정의와 성질 (a > 0, a ≠ 1, M > 0, N > 0)
\[ a^x = N \iff x = \log_a N \]
\[ \log_a MN = \log_a M + \log_a N,\qquad \log_a \frac{M}{N} = \log_a M - \log_a N,\qquad \log_a M^k = k\log_a M \]

왜 곱이 합이 될까. M = aᵐ, N = aⁿ이라 하면 MN = aᵐ⁺ⁿ입니다(지수법칙). 양쪽에 로그를 취하면 log MN = m + n = log M + log N. 지수에서 곱셈이 덧셈이 되던 성질이 로그로 옮겨 온 것입니다.

그래프. y = 2ˣ과 y = log₂ x는 입력과 출력을 맞바꾼 관계(역함수)라서, 그래프가 직선 y = x에 대해 대칭입니다. 점 (p, q)와 (q, p)를 잇는 선분은 기울기가 −1이고 중점이 y = x 위에 있으므로, y = x가 이 선분을 수직이등분합니다(고등 1의 수직 조건). 특히 log₂ 2x = log₂ x + 1이므로 입력을 두 배로 하면 높이가 정확히 1 오릅니다. 높이를 1 올리려면 입력을 두 배로 늘려야 하니, 로그 그래프는 오른쪽으로 갈수록 몹시 느리게 올라갑니다.

상용로그. 밑이 10인 로그를 상용로그라 하고 밑을 생략해 log N으로 씁니다. log 2 ≈ 0.3010, log 3 ≈ 0.4771은 자주 쓰는 값입니다.

교과서에서

호도법. 반지름이 r인 원에서 길이가 r인 호에 대한 중심각을 1라디안이라 합니다. 원둘레는 2πr이므로 한 바퀴 360°는 2π 라디안, 180°는 π 라디안입니다.

핵심 공식 · 호도법과 삼각함수
\[ 180^\circ = \pi\ \text{rad},\qquad 1\ \text{rad} = \frac{180^\circ}{\pi} \approx 57.3^\circ \]
  • 원점이 중심이고 반지름이 r인 원 위의 점 P(x, y)에 대해, 동경 OP가 나타내는 각이 θ일 때 sin θ = y/r, cos θ = x/r, tan θ = y/x
  • y = a sin bx의 최댓값 |a|, 최솟값 −|a|, 주기 2π/|b|

그래프. 반지름이 1인 원(단위원) 위를 점이 시계 반대 방향으로 돌면, 점의 높이가 sin θ, 가로 위치가 cos θ입니다. 높이를 옆으로 펼쳐 그리면 0 → 1 → 0 → −1 → 0을 되풀이하는 물결이 되고, 원을 한 바퀴 돌 때마다 같은 모양이 반복되므로 주기는 2π입니다.

주기가 2π/b인 이유. y = sin bx에서 안쪽의 bx가 0에서 2π까지 한 바퀴를 돌아야 물결 하나가 완성됩니다. bx = 2π가 되는 x는 2π/b이므로, b가 클수록 주기가 짧아집니다.

(1) 150° × π/180° = 5π/6

(2) 최댓값은 3, 최솟값은 −3이고, 주기는 2π/2 = π입니다.

교과서 단원미적분 Ⅰ미분계수와 도함수미적분 Ⅱ삼각함수의 미분

sin x를 미분하면 왜 cos x가 될까?

교과서 그래프 = 무선 그래프
상태: 결과 화면
① 나란히② 겹치기③ 기호 짝

교과서에서

미분계수. 곡선 위의 두 점을 잇는 직선의 기울기(평균변화율)에서, 두 번째 점을 첫 번째 점으로 한없이 가까이 가져가면 그 점에서의 접선의 기울기가 됩니다. 이것이 미분계수이고, 각 x에 미분계수를 대응시킨 함수가 도함수 f′(x)입니다.

핵심 공식 · 미분계수와 삼각함수의 도함수
\[ f'(a) = \lim_{h\to 0}\frac{f(a+h) - f(a)}{h} \]
\[ (\sin x)' = \cos x,\qquad (\cos x)' = -\sin x \]

교과서의 증명. 삼각함수의 덧셈정리 sin(x + h) = sin x cos h + cos x sin h를 넣으면

\[ \frac{\sin(x+h) - \sin x}{h} = \sin x \cdot \frac{\cos h - 1}{h} + \cos x \cdot \frac{\sin h}{h} \]

h → 0일 때 \(\frac{\sin h}{h} \to 1\), \(\frac{\cos h - 1}{h} \to 0\)이므로 극한값은 cos x입니다. 여기서 \(\frac{\sin h}{h}\to 1\)은 각을 라디안으로 쟀기 때문에 성립합니다. 아주 작은 각에서는 높이 sin h와 호의 길이 h가 거의 같아지기 때문입니다.

그림으로 보는 이유. 단위원 위의 점은 각이 h만큼 늘 때 정확히 h만큼의 호를 움직이므로 속력 1로 움직입니다. 중심에서의 거리는 늘 1이라 반지름 방향으로는 움직이지 않으니, 속도는 반지름에 수직입니다. 반지름 방향 (cos θ, sin θ)를 90° 돌리면 고등 1에서 본 대로 (−sin θ, cos θ)가 되고, 속도의 세로 성분 cos θ가 높이 sin θ의 변화율입니다.

예제

곡선 y = sin x 위의 점 (π/3, √3/2)에서의 접선의 기울기를 구하시오.

풀이 보기풀이 접기

y′ = cos x이므로 접선의 기울기는 cos(π/3) = 1/2입니다. 아래 그림에서 θ를 π/3(약 1.05)에 두고 접선의 기울기를 확인할 수 있습니다.

왼쪽: 반지름(청록)과 속도(분홍) · 오른쪽: sin(청록)과 cos(분홍), 갈색은 sin 곡선의 접선

콘덴서
두 금속판 사이에 전하를 모으는 부품. 모인 전하는 q = Cv(C는 정전용량, v는 전압)입니다.
전류
1초에 지나가는 전하의 양, 곧 전하의 변화율입니다. i = dq/dt.
코일
전선을 감은 부품. 전류가 바뀌면 그 변화를 막는 전압이 생깁니다. v = L·di/dt.

콘덴서에 흐르는 전류는 전하의 변화율이고, 전하는 전압에 비례하므로 전류 = C × (전압의 변화율)입니다. 교류 전압 v = V sin ωt를 넣으면 sin을 미분하게 됩니다. (안쪽이 ωt라서 미분하면 ω가 앞으로 나옵니다. 미적분 Ⅱ의 합성함수의 미분입니다.)

함수미분하면그래프로 보면
배운 식삼각함수의 미분y = sin xy′ = cos xcos가 sin보다 90° 앞섬
무선 식콘덴서v = V sin ωti = C·v′ = ωCV cos ωt전류가 전압보다 90° 앞섬

sin을 미분하면 cos가 되므로, 콘덴서에서는 전류가 전압보다 90° 앞섭니다. 코일은 반대로 전압이 전류보다 90° 앞섭니다.

리액턴스 공식이 여기서 나옵니다

위 식에서 전류의 꼭대기 값은 I = ωCV입니다. 전압을 전류로 나누면 콘덴서가 방해하는 정도가 나옵니다.

\[ \frac{V}{I} = \frac{V}{\omega C V} = \frac{1}{\omega C} = \frac{1}{2\pi f C} = X_C \]

코일도 같은 방법으로 전류 i = I sin ωt를 미분하면 v = L·i′ = ωLI cos ωt이므로 V/I = ωL = 2πfL = XL입니다. 중등 3에서 정비례와 반비례로 만났던 두 식은, 미분할 때 ω가 앞으로 나오는 방식(곱해지느냐 나눠지느냐)에서 생긴 것입니다.

곡선 y = x² 아래, 0부터 1까지의 넓이는 왜 1/3일까?

교과서 그래프 → 무선 그래프 (같은 원리)
상태: 결과 화면
① 교과서 그래프② 변하기③ 기호 짝

교과서에서

구분구적법. 구간 [0, 1]을 n등분하고, 각 조각 위에 높이가 오른쪽 끝의 함숫값인 막대를 세웁니다. k번째 막대는 폭이 1/n, 높이가 (k/n)²이므로 막대 넓이의 합은

\[ S_n = \sum_{k=1}^{n} \left(\frac{k}{n}\right)^2 \frac{1}{n} = \frac{1}{n^3}\sum_{k=1}^{n} k^2 = \frac{1}{n^3}\cdot\frac{n(n+1)(2n+1)}{6} \]

n이 커질수록 (n + 1)(2n + 1)은 2n²에 가까워지므로 \(S_n \to \frac{2n^3}{6n^3} = \frac{1}{3}\)입니다. n = 10이면 0.385, n = 100이면 0.33835로 1/3에 다가갑니다.

Σk² = n(n+1)(2n+1)/6은 대수의 「수열의 합」, 막대 합의 극한으로 정적분을 구하는 방법은 미적분 Ⅱ의 「정적분과 급수의 합」에서 배웁니다. 미적분 Ⅰ에서는 정적분을 아래의 F(b) − F(a)로 계산합니다.

정적분과 기본정리. 막대를 한없이 잘게 나눈 극한이 정적분이고, f(x) ≥ 0인 구간에서는 이 값이 곡선 아래 넓이와 같습니다. 그런데 넓이 함수를 x만큼 넓히면 높이 f(x)인 얇은 막대만큼 늘어나므로, 넓이 함수를 미분하면 원래 함수가 됩니다. 그래서 미분하면 f(x)가 되는 함수 F(x)를 찾으면 넓이를 바로 계산할 수 있습니다.

핵심 공식 · 정적분
\[ \int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{k=1}^{n} f(x_k)\,\Delta x = F(b) - F(a) \quad (F'(x) = f(x)) \]
예제

(1) \(\int_0^1 x^2\,dx\)를 구하시오.
(2) sin²θ + cos²θ = 1을 이용하여 0 ≤ θ ≤ π/2에서 sin²θ의 평균값을 구하시오.

풀이 보기풀이 접기

(1) (x³/3)′ = x²이므로 \(\int_0^1 x^2\,dx = \frac{1^3}{3} - \frac{0^3}{3} = \frac{1}{3}\). 구분구적법의 결과와 같습니다.

(2) 0부터 π/2까지 sin²θ와 cos²θ의 그래프는 좌우를 뒤집은 모양이라 아래 넓이가 같습니다. 두 함수를 더하면 언제나 1이므로 두 넓이의 합은 1 × π/2입니다. 넓이가 같으니 각각 π/4이고, 구간의 길이 π/2로 나눈 평균값은 1/2입니다. (sin²θ의 부정적분은 미적분 Ⅱ의 배각공식이 필요하지만, 대칭을 쓰면 그 전에도 답을 낼 수 있습니다.)

핵심 공식 · 평면벡터 a = (a₁, a₂), b = (b₁, b₂)의 내적
\[ \vec a \cdot \vec b = |\vec a||\vec b|\cos\theta = a_1 b_1 + a_2 b_2 \]
  • 두 벡터가 수직 ⇔ a · b = 0
  • 두 벡터가 이루는 각: cos θ = (a · b) / (|a||b|)

성분 공식이 수직 조건이 되는 이유. 벡터 a = (p, q)의 끝에 b = (r, s)를 이어 붙이면, 출발점에서 끝점까지의 a + b = (p + r, q + s)와 함께 삼각형이 생깁니다. a와 b가 수직이면 직각삼각형이므로 피타고라스 정리가 성립해야 합니다. 가장 긴 변의 제곱을 전개하면

\[ (p+r)^2 + (q+s)^2 = (p^2+q^2) + (r^2+s^2) + 2(pr+qs) \]

피타고라스 정리가 성립하려면 남는 항 2(pr + qs)가 0이어야 하고, pr + qs가 바로 내적입니다. 기울기가 m, m′인 두 직선의 방향 (1, m), (1, m′)에 적용하면 1 + mm′ = 0, 곧 mm′ = −1. 고등 1의 공식은 내적의 특별한 경우였고, 수평선 (1, 0)과 수직선 (0, 1)처럼 기울기로는 판정할 수 없는 경우도 내적은 1·0 + 0·1 = 0으로 판정합니다.

그림에서 θ를 읽는 법. 두 벡터가 이루는 각 θ는 두 벡터의 시작점을 한 점에 맞췄을 때의 각입니다. 아래 그림처럼 a 끝에 b를 이어 붙이면 꼭짓점 A의 내각은 180° − θ가 되므로, θ는 a의 연장선(점선)과 b 사이의 각으로 표시했습니다. 수직(θ = 90°)일 때만 둘이 같습니다.

코사인이 나오는 이유. b를 a 방향으로 비춘 그림자의 길이가 |b| cos θ이고, 내적은 a의 길이에 이 그림자의 길이를 곱한 값입니다.

예제

(2) 두 벡터 a = (1, 0), b = (1, 1)이 이루는 각의 크기를 구하시오.

풀이 보기풀이 접기

(1) a · b = 1 × 4 + 2 × (−2) = 0이므로 수직입니다. 피타고라스로 확인하면 |a|² + |b|² = 5 + 20 = 25, |a + b|² = 5² + 0² = 25로 같습니다.

(2) a · b = 1, |a| = 1, |b| = √2이므로 cos θ = 1/√2, θ = 45°입니다.

임피던스 평면을 Γ로 색칠 · 색 = Γ의 각도, 밝기 = |Γ|
